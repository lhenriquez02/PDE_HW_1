# PDE_HW_1

Numerical PDEs Homework #0 — finite-difference derivative computations in MATLAB, with a typed-up report.

**The report can be accessed by opening `Hw0.pdf`.**

## Files

- `Hw0.tex` — LaTeX source for the homework report.
- `Hw0.pdf` — the compiled report (open this to view the full write-up).
- `question1.m` — MATLAB script for Problem 1: first derivative of $f(x)=e^{\sin x}$ via second-order centered differences (one-sided at the endpoints) and its convergence study.
- `question2.m` — MATLAB script for Problem 2: second derivative via finite differences and the associated convergence plot.
- `question3.m` — MATLAB script for Problem 3: convergence study over a range of grid sizes N.
- `Question1.prj` — MATLAB project file.
- `question2.asv` — MATLAB autosave file (generated automatically while editing `question2.m`).

## Figures (generated by the scripts above, included in the report)

- `finiteDifferenceQ1a.pdf` — exact vs. numerical first derivative for Problem 1a.
- `convergenceq1.pdf` — relative error convergence plot for Problem 1b.
- `secondDerivative.pdf` — exact vs. numerical second derivative (Problem 2).
- `secondDerivativeConvergence.pdf` — convergence plot for the second derivative.
- `convergencePlot.pdf` — additional convergence plot (Problem 3).
